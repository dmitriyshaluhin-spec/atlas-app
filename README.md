# АТЛАС — автономная фабрика видеоконтента

Атлас сам пишет сценарии, озвучивает их, генерирует видеоряд, монтирует ролики и публикует их в соцсети по расписанию. Дальше — следит за комментариями, трендами и запасом готовых роликов.

Всё работает **на твоём компьютере**: рендер идёт на твоём железе (никаких счетов за сервер), а публикация — с твоего домашнего интернета (соцсети видят обычного человека, а не «спам-ферму» с чужого IP).

---

## 1. Быстрый старт

1. Распакуй папку `AtlasCommercial` куда угодно (например, на рабочий стол).
2. **Запусти `setup_atlas.bat`** (двойной клик). Откроется чёрное окно — это нормально, идёт проверка и установка.
3. **Если установщик попросит поставить Python** — сам откроется браузер и начнётся скачивание нужной версии.
   - Запусти скачанный файл `python-3.12.8-amd64.exe`.
   - **ОБЯЗАТЕЛЬНО** поставь галочку **«Add python.exe to PATH»** (внизу первого окна установки Python), затем нажми **Install Now**.
   - После установки Python **запусти `setup_atlas.bat` ещё раз** — он **продолжит с того шага, где остановился** (обычно с шага 4). Подожди 2-3 минуты: библиотеки ставятся молча, окно «висит» — это нормально.
4. Когда увидишь **«ГОТОВО!»** — на рабочем столе появится ярлык **«Атлас»**.
5. Открой файл `.env` (обычным Блокнотом) и впиши свои ключи API — см. раздел 2.
6. Запусти ярлык **«Атлас»** → откроется экран активации (см. раздел 1.1).

> **Важно:** окно, которое открывается при запуске Атласа, **не закрывай** — пока оно открыто, Атлас работает: публикует по расписанию и пополняет запас роликов.

### 1.1 Активация — как получить доступ

При первом запуске Атлас покажет экран **«Введите лицензионный ключ»**. В самом низу этого экрана есть строка:

```
ID компьютера:  52012D9BA473DC51BE0CBA9AC7950559
```

(у тебя будет свой набор букв и цифр — он привязывает лицензию именно к твоему компьютеру).

**Что делать:**
1. **Скопируй свой `ID компьютера`** — выдели мышкой и нажми Ctrl+C.
2. **Отправь его продавцу** (туда, где покупал Атлас).
3. Продавец пришлёт тебе файл **`atlas_license.lic`**.
4. **Положи этот файл в папку Атласа** — туда же, где лежат `setup_atlas.bat` и ярлык.
5. **Перезапусти Атлас** — экран активации исчезнет, откроется панель управления. Ключ в поле вводить не нужно — активирует именно файл.

> Лицензия привязана к одному компьютеру. Сменил ПК — попроси продавца отвязать ключ и назови новый `ID компьютера`.

### Что установщик поставит сам
| Что | Зачем |
|---|---|
| **Python 3.12** *(рекомендуется)* | на нём работает Атлас — единственное, что может попросить поставить вручную (см. шаг 3) |
| **FFmpeg** | монтаж роликов, титры, звук — без него ролики не соберутся |

| **Библиотеки Python** | мозги и руки агентов |
| **Движок Playwright** | автоматизация браузера |

## 2. Ключи API (где взять)

Ключи хранятся **только на твоём компьютере**, в файле `.env`. Никуда не отправляются.

| Сервис | Зачем нужен | Где взять |
|---|---|---|
| **Google Gemini** | сценарии, описания, тренды, ответы на комментарии | https://aistudio.google.com/apikey |
| **ElevenLabs** | озвучка роликов живым голосом | https://elevenlabs.io → Profile → API Keys |
| **Anthropic Claude** *(необязательно)* | альтернативный ИИ для текстов | https://console.anthropic.com/settings/keys |

Открой `.env` Блокнотом и вставь ключи после знака `=`, без кавычек:

```
GEMINI_API_KEY=твой_ключ_сюда
ELEVENLABS_API_KEY=твой_ключ_сюда
```

Сохрани файл и перезапусти Атлас.

### ⚠️ Важно про ключи Gemini (бесплатные vs платные)

Атлас — «умный»: чтобы принять решение, он читает файлы, сканирует проект и делает
**много запросов** к Gemini. У **бесплатного** ключа жёсткие лимиты (примерно **15
запросов в минуту** и суточная квота), поэтому на сложных задачах он быстро упирается
в лимит — появляется ошибка `503` или `Лимит Gemini исчерпан`.

Что делать:
- **Для реальной работы — платный ключ Gemini.** Тогда Атлас работает без оглядки на лимиты.
- **Хочешь на бесплатных — заведи 2-3 ключа** на разные Google-аккаунты. Атлас **сам
  переключится** на следующий, когда первый упрётся в лимит:
  ```
  GEMINI_API_KEY=ключ_1
  GEMINI_API_KEY_2=ключ_2
  GEMINI_API_KEY_3=ключ_3
  ```
- **Anthropic Claude** как запасной мозг (если Gemini в лимите): `ANTHROPIC_API_KEY=...`.

Одного бесплатного ключа хватает только на лёгкие пробы, не на полноценную работу.

**Отдельно понадобятся аккаунты** (логинишься один раз прямо из панели, в разделе «Мои каналы»): TikTok, Instagram, X, YouTube — те, куда будешь публиковать.

=== НАДЗИРАТЕЛЬ (Sentinel) ===

• «Сценарист не работает / нет сценариев»

• «Ролики не собираются»

• «В видео нет титров / QR / скриншота»

    QR и screen*.jpg должны лежать в projects/<Проект>/assets/.

• «Описание не в том стиле / не те хэштеги»
  → Это brand.json → caption. Править персону, тему и хэштеги по каждому языку.

  → Мало сырья: добавить визуал-промптов и футажа, положить больше музыки в safe_bgm/,

Не выдумывает функции продукта (только из product_info.txt). Не покупает сырьё и не

## 4. Как дать ИИ доступ к своим настройкам

Чтобы ИИ давал советы **именно по твоему проекту**, а не общие:

1. Открой папку `projects/<ТвойПроект>/`.
2. **Перетащи в чат с ИИ файл `brand.json`** (после системного промпта из раздела 3).
3. Напиши, например:
   - «Разбери мой brand.json — что заполнено плохо?»
   - «Почему у меня в английских постах русские хэштеги?»
   - «Предложи хэштеги под мою нишу»

Так же можно прислать:

| Файл | Когда присылать |
|---|---|
| `brand.json` | вопросы про описания, хэштеги, тон, расписание |
| `product_info.txt` | «сценарии не о том», «Атлас выдумывает» |
| `setup_log.txt` | проблемы установки |
| текст ошибки из чёрного окна | всё не запускается |

> ⚠️ **Никогда не отправляй в чат файл `.env`** — там твои ключи API. Если случайно отправил — сразу перевыпусти ключи на сайтах сервисов.

## 5. Ежедневная работа

| Что | Где |
|---|---|
| Создать проект | Панель → **Мастер проектов** |
| Настроить бренд, хэштеги, время публикации | Мастер проектов → развернуть проект |
| Подключить соцсети | **Мои каналы** → «Подключить и войти» |
| Поставить проект на паузу | **Автопилот** → снять галочку |
| Посмотреть остаток роликов | **Sentinel** → несгораемый остаток |
| Узнать, чего не хватает | **Sentinel** → Алерты / Снабжение |
| Свои видео → ролики, своё фото → премиум-кадр | **Шлюз сырых материалов** (см. 5.1) |

**Первый запуск проекта — по шагам:**
1. Создай проект (имя + языки).
2. Заполни `product_info.txt` — чем подробнее, тем лучше ролики.
3. Положи в `projects/<Проект>/assets/` скриншоты приложения (`screen1.jpg`…) и свой QR-код.
4. Подключи соцсети в «Мои каналы».
5. Включи Автопилот и Sentinel — дальше Атлас работает сам.

### 5.1 Шлюз сырых материалов — свои видео и фото

В панели есть блок **«📥 Шлюз сырых материалов»** — через него ты отдаёшь Атласу **своё**.

**А) Свои видеоклипы → ролики.** Нажми «Открыть папку», скопируй туда свои `mp4`, затем
словами напиши инструкцию — например: *«Сделай из этих клипов нарезку по 15 секунд,
наложи музыку и опубликуй в TikTok и YouTube в пн/ср/пт в 13:15»* — и нажми **«Передать
Атласу»**. Атлас сам разберёт задачу и выполнит её доступными инструментами.

**Б) Своё фото/видео → премиум-картинка.** Ниже, в блоке **«🖼️ Своё фото/видео →
премиум-картинка»**:
1. Загрузи фото товара (или видео — Атлас сам возьмёт из него кадр).
2. В поле **«Сцена»** опиши, где показать товар: *«на пляже, золотой час, пальмы»*,
   *«в студии на мраморе»*, *«в горах на рассвете»*.
3. Выбери, сколько кадров сделать, и нажми **«Сделать премиум-кадр»**.

Откроется браузер, и Атлас через **Meta AI** сделает премиум-рекламный кадр, **сохранив
сам товар** — форму, цвет, логотип; а если на фото человек или аватар — лицо и одежду.
Готовые кадры лягут в склад слайдов проекта и пойдут в слайд-рекламу.

> 💡 Это **бесплатно**: картинки рисует Meta AI прямо в браузере, а не платный API. Нужен
> лишь один раз войти в аккаунт Meta (так же, как соцсети в «Мои каналы»).

### 5.2 Генерация видео-футажа через Vibes — под присмотром

Премиум-видеофутаж (оживлённые кадры) Атлас делает через **Vibes** прямо в браузере — это
**бесплатно**, но у процесса есть важная особенность: **нужно быть рядом с ПК.**

**Как правильно:**
- Планируй **~2 дня** на наполнение всех папок футажа (`intro`, `cta`, и категории продукта),
  **по одной папке за раз**, спокойно, под присмотром.
- Vibes — бета-инструмент, и **иногда** (не всегда) нужно чуть **«подтолкнуть»**: нажать
  «Log In», если он попросит вход, или подождать, пока прогрузятся ролики. Это мелкие
  причуды нынешних ИИ-технологий — просто **поглядывай** за окном браузера, не отходи надолго.
- **Не торопи** генерацию: если ролики ещё грузятся — дай им время, не закрывай окно.

**Когда можно расслабиться:** как только в **каждой папке набралось не менее 10 клипов** —
всё, футаж укомплектован **с запасом**. Конвейер публикаций будет крутиться сам, а
**обновлять футаж имеет смысл не раньше, чем через месяц** (чтобы контент не приедался).

> ⚠️ Пока идёт генерация в Vibes — не запускай второй такой процесс параллельно: браузер
> один, они помешают друг другу. Одна папка → следующая.

**🔒 ЖЕЛЕЗНОЕ ПРАВИЛО Vibes (вывели опытным путём — соблюдать строго):**
1. **Не более 8 промптов в одном чате.** Больше — Vibes включает анти-бот (мигание,
   «серые» ролики, дубли, окно логина, а то и «Something went wrong»).
2. **После скачивания роликов каждого промпта — перезагрузка страницы** (гигиена сессии,
   ролики докручиваются чисто).
3. **Отработали 8 промптов → полностью закрываем браузер → продолжаем с НОВОГО чата.**
   Свежая сессия снимает накопленный анти-бот и «битую» сессию.
4. **Только под присмотром пользователя** — быть рядом, чтобы нажать «Log In» и не пропустить
   зависание. Отходить надолго нельзя.
5. Каждый ролик после скачивания проверяется по контрольной сумме (md5) — **точные дубли
   отсеиваются**, и Атлас **добирает недостающее до нужного числа**, а не гонит всё по новой.
